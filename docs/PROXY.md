# 家庭／住宅代理出口配置与排查

## 本项目为什么需要家庭出口

本项目原部署遇到过云服务器的机房 IP 无法正常登录抖音的情况，因此使用家庭／住宅网络出口。对于同类部署，应先准备可用的家庭出口，再完成抖音登录。

```text
云服务器（运行机器人）
    ↓ 连接代理
家庭／住宅网络（实际向抖音发送请求）
    ↓ 家庭宽带出口 IP
抖音
```

机器人仍然运行在云服务器上，变化的是抖音连接最终从哪里出去。HTTP/SOCKS5 是代理协议，家庭/机房是出口网络属性：**支持 SOCKS5 不代表就是家庭出口**。换另一台云服务器作跳板，最终仍可能是机房 IP。

这描述的是原部署遇到的问题与采用的方案，不代表所有机房 IP 都被禁止，也不保证家庭出口一定能登录。账号登录态、网页验证和网络稳定性仍需分别检查。

## 家庭出口从哪里来

| 方式 | 需要自行准备 |
| --- | --- |
| 自己家里的设备转发 | 家庭宽带、持续开机的设备，以及云服务器到家庭设备的安全连接方式 |
| 自己有权使用的住宅代理服务 | 服务地址、端口、协议，以及按服务要求配置的认证或访问白名单 |

最终连接应从家庭／住宅网络发出。家庭设备位于 NAT 后面时，云服务器通常不能直接使用它的局域网地址；需要自行配置安全组网或转发。不要把家中的无认证代理直接开放到公网。

如果使用电脑提供家庭出口，该电脑、代理程序及连接链路都需要持续在线。仓库不包含家庭网络节点、住宅代理服务订阅或私人认证信息。

## 先理解两种地址

- **模型接口地址**：`ai.base_url`，告诉程序向哪家模型服务请求回复。
- **代理出口地址**：`account.proxy_server`，告诉抖音浏览器经过哪条网络线路访问抖音。

它们不是同一个设置，也不能互相替代。这个仓库不提供代理节点或购买渠道，部署者需要准备自己有权使用的代理服务。

## 什么时候要配

云服务器部署首先检查是否存在机房 IP 登录问题；存在时，先配置家庭／住宅出口。若直接连接已经能登录、打开正确好友会话、读取并发送消息，也可把 `proxy_server` 留空。

若存在网络连接失败，可用自己的代理线路排查。仅凭“无法查看视频”或“不回复”不能认定是出口问题；登录失效、身份校验、卡片不可用和模型接口失败也会导致功能不正常。更换代理不是绕过抖音验证的保证。

## 填写位置和示例

编辑 `douyin-friend-ai-bot/config/config.json` 的 `account` 对象，只改其中的代理字段，不要覆盖其他设置：

```json
"proxy_server": "socks5://127.0.0.1:1080"
```

| 场景 | 字段值示例 |
| --- | --- |
| 不使用代理 | `""` |
| 同一台服务器的 HTTP 代理 | `http://127.0.0.1:7890` |
| 同一台服务器的 SOCKS5 代理 | `socks5://127.0.0.1:1080` |
| 另一台设备提供的代理 | `socks5://proxy.example.com:1080`（替换为自己的可达地址） |

这些只是格式示例，不会自动创建对应端口。`127.0.0.1` 是机器人所在服务器的本机地址；电脑上的代理软件和服务器是两个环境。

浏览器代理协议参考 [Playwright 官方网络文档](https://playwright.dev/python/docs/network#http-proxy)。本项目目前只向 Playwright 传入 `server` 字段，**没有提供独立的代理 username/password 配置**。不要把账号密码直接嵌入代理 URL 当作已验证支持的配置。

需要认证的代理可以先通过你自己的本地转发服务处理上游认证，机器人连接该转发服务的本机端口。不要将无认证转发端口开放到公网；真实上游账号密码只保存在本地私密配置中。

## 可选：连接自己家庭网络的 SSH 设备

如果家庭网络中有一台你能安全连接的 SSH 设备，且该设备通过家庭宽带访问互联网，可以在**机器人所在云服务器**上建立 SSH SOCKS 转发：

```bash
ssh -N -D 127.0.0.1:1080 -o ExitOnForwardFailure=yes -o ServerAliveInterval=30 user@你的家庭SSH设备地址
```

前提是云服务器确实能连接该家庭设备，并且你有它的 SSH 权限；家庭设备若在 NAT 后面，需要先解决安全连接问题，不能直接照抄家中局域网 IP。命令会保持运行，关闭连接后代理也会停止；初次连接需核实 SSH 主机指纹。配置机器人的 `proxy_server` 为 `socks5://127.0.0.1:1080`。

这里的 SSH 设备必须是你准备的家庭网络出口。如果填写另一台机房服务器的地址，得到的是那台机房服务器的出口。

这是临时连通性验证方式。长期运行需自行将转发服务纳入进程管理，设置掉线重连和开机启动；本项目安装脚本不会替你配置出口服务器或保存 SSH 密钥。

## 哪些请求会受影响

| 请求 | 是否读取 `account.proxy_server` |
| --- | --- |
| 抖音浏览器登录、聊天页收发 | 是 |
| 视频评论读取 | 使用同一抖音浏览器上下文 |
| 故障监视器的抖音代理探测 | 是，使用该代理地址单独探测 |
| 基础 AI 模型请求 | 不读取此字段；可能另受 Python HTTP 客户端环境设置影响 |
| 幕间模型请求 | 不读取此字段；模型接口本身仍需可达 |
| 机器人与幕间的本机桥接 | 本机直连 |
| QQ 邮件提醒 | SMTP 直连，不经过抖音代理 |

## 如何检查

在机器人服务器上执行与配置相同协议和端口的检查。例如 SOCKS5：

```bash
curl --proxy socks5h://127.0.0.1:1080 --connect-timeout 10 --max-time 20 -I https://www.douyin.com/
```

HTTP 代理：

```bash
curl --proxy http://127.0.0.1:7890 --connect-timeout 10 --max-time 20 -I https://www.douyin.com/
```

`socks5h` 是 curl 的写法，用于让代理处理域名解析；机器人配置示例使用 `socks5://`。

收到目标网站的 HTTP 响应只说明此次传输有响应，不证明登录有效、聊天接口可用或能实际发消息。还需要停止正在运行的机器人，再使用同一配置检查登录：

```bash
sudo systemctl stop douyin-friend-ai-bot
cd /opt/douyin-bot/douyin-friend-ai-bot
export DISPLAY=:99
export PLAYWRIGHT_BROWSERS_PATH="$PWD/ms-playwright"
.venv/bin/python src/main.py --check-login
sudo systemctl start douyin-friend-ai-bot
```

最后让白名单好友发一条新消息，核对真实收信与发送日志。检查登录的命令也需要人工有效的 Cookie，不会自动获取账号权限。

## 失败时从哪里查

- `Connection refused`：检查地址、端口、代理进程是否在服务器上运行。
- 超时或连接断开：检查服务器到代理、代理到抖音两段连接。
- HTTP `407`：通常是代理要求认证；当前配置没有独立认证字段，请使用合适的本地转发。
- 网页能打开但聊天不正常：继续检查登录、验证提示、好友身份绑定和具体运行日志。
- AI 请求失败：检查模型接口，不能只调整抖音代理。

修改代理地址后重启 `douyin-friend-ai-bot`，无需为此更改角色设定。若已配置故障邮件和定时器，持续代理故障会按设置提醒；代理检测获得 HTTP 响应也不等于完成聊天功能验证。
