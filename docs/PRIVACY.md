# 隐私与公开发布

此公开版本从代码白名单导出，不继承生产仓库 Git 历史。

未导出生产配置、人设、好友名单、Cookie、浏览器 profile、数据库、聊天日志、邮件设置、面板令牌、SSH 密钥、服务器备份、虚拟环境或 node_modules。示例角色“小禾”和“示例助手”是虚构内容。

源码里的私人域名、好友昵称和旧部署痕迹已移除或泛化。上游作者的公开项目地址、许可证和说明保留作为来源信息。

## 你部署后会产生什么

- `config.json`：AI 密钥、代理设置、账号和好友身份。
- `persona.md` 和 `bridge-config.json`：角色设定、桥接令牌、剧情配置。
- `state/`：Cookie、浏览器 profile、已处理消息状态、评论缓存。
- `data/`：幕间剧情与记忆数据库、邮件设置、待发送队列。
- `logs/`：运行日志、含聊天内容的审计日志和可能的截图。
- `panel_token`：面板管理员令牌。

这些内容都应仅保存在自己的设备上，仓库已设置 `.gitignore`。不要使用 `git add -f` 强行提交它们。

## 数据会发到哪里

机器人访问抖音；模型服务会接收用于生成的聊天上下文、人设、评论参考及配置启用的图片。邮箱服务会接收故障通知。它们是否保留数据取决于你选择的服务；项目不会自动把数据上传到本仓库作者的服务器。

## 再次公开前

运行 `python3 scripts/check_public_release.py`，并人工检查 `git diff --cached`。检查器能发现常见密钥格式、运行文件和疑似真实身份标记，但不能证明任意新增自然语言都没有隐私。

不要把真实聊天截图当作演示图；不要在 issue 中粘贴 Cookie、API Key、SMTP 授权码或完整私密日志。
