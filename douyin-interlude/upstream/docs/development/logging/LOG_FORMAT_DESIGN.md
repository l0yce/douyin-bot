# 日志格式设计约束

1. 一个标准日志回答“正在做什么、结果怎样、是否需要处理”，并保持内部对象留在诊断层。
2. 阶段和主角只在任务主行出现；子项使用树形字段。
3. 颜色表达语义，不装饰正文：青色接收、绿色成功、黄色可恢复问题、红色失败、紫色 Alter、蓝色后台生活与记忆。
4. 颜文字固定映射，不能随机选择。
5. 用户消息正文、主角回复、剧本和网页节选由独立隐私开关控制。
6. 周期扫描、跳过原因、故事 ID、队列和数据库暂态只属于 diagnostic。
7. Provider 内部失败只在 debug 显示；最终失败由主叙事或 Alter 业务记录统一呈现。
8. 日志字符串保持可搜索的中文关键词，例如“模型调用失败”“Alter 累积触发”“记忆整理完成”。
